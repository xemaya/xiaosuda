## 已确定的方向

- 面向儿童，以Soda的旅行发现、角色互动和一个可观察的问题推动故事；主角身份、声线和毛绒画风保持一致。蜀道难已按用户要求增加本集匿名毛绒群演，具体造型/声音另存，不扩写主角家庭关系。
- **真实照片/视频参考→统一毛绒动画风**。地标轮廓、方位关系与知识有出处；不能凭空拼出新山体、假景点或假历史。角色体验和构图前景可以原创，并与地理事实区分。
- 原设想每集约3分钟，系列上限仍为含包装5分钟。黄山最终2:21.21，已经交付，不为凑3分钟补静帧。
- 运镜优先同侧固定、克制的推近/拉远/左右位移。风、树梢、云、水、小鸟可以提供动感，山峰、石猴与主树干保持稳定；不以旋转镜头补造未知空间。
- Soda默认自然犬坐、四足站立/行走/奔跑。核对脸、花色、两只耳朵、背包、四条腿和材质，不能用第一集特殊直立表演替代全系列姿态依据。顺毛仍要保留柔软纤维与立体毛束。
- 生图/改图优先自有4090 Qwen-Image-2.1，agent负责约束和审核；用户另行同意后才换来源。视频仍用v14的原生H3短窗与纯画面续接。
- 只改一个问题时，保留已好的原表演与原声，优先检查后期取景/切镜能否完成；新候选不覆盖已交付文件。

## 故事的共用方法

下一集《蜀道难》的具体安排见制作入口；以下方法供各集按题材调整。

用一个孩子能理解的疑问开场，让观察或误会推进旅程；选择少量有区别的景观，以一段轻量史实或明确标注的传说增加记忆点，再用角色自己的行动收尾。黄山用了“石猴在看什么→原来是云海→把旅行画进手账”，后续不必每集重复石猴式误会或手账结尾。

知识融入角色眼前的经历。给风景留短暂观看时间：静默镜头中的人物嘴必须闭合；纯风景、手部/道具特写、画外音镜头都可作为有叙事目的的切镜。不要让所有地点都长成“两山夹一片云”的背景。

## 工作台现状

当前是有人审看的半自动流程。已有工作台提供剧本/设定/主图/分镜/配音/拍摄/采用/合成与回执；真实地点资料管理、画外音与纯风景镜头契约、复杂AddGuide、视觉审核、部分混音/后期仍有单片适配。**不能把黄山脚本当成任意目的地的一键产线。**

2026-10-18首次文档整理时只读查到黄山源项目仍是revision20、`ready_to_shoot`、`adopted_takes={}`、`final_asset=null`。最终片通过独立制片快照和本地后期完成。线上状态不代表“黄山没做”，也不证明最终V4已在线上采用；应先读release与交接记录，写入前重新读当前版本。
