# 环游世界：从选题到交付

本手册补充[通用制片接手文档](../agent-handoff.md)。角色、风格、声线及权限仍以当前AGENTS和系列口径为准。这里是已验证方法与人工操作清单，不是自动执行脚本。

## 1. 新片输入和目录

先明确本集目的地/地理范围、故事问题、出镜角色、语言和大致时长。用户已经指定的内容直接沿用，不反复确认；缺少会影响剧情或配音的决定时，再提出具体选项。黄山是中文旅行试片，不能据此把下一集自动锁成中文或英语教学。

新集建议使用：

- `episodes/travel/<目的地或故事slug>/`：剧本、参考清单、对白、分镜、采用索引。
- `jobs/<日期>-<slug>-<目的>-vN/`：每轮执行和审核证据。
- `releases/<slug>/<日期>/`及`current.json`：经用户确认的最终交付。

沿用现有soda服务和数据库，以现有项目/版本对象承载新作品；新地点不要覆盖黄山项目或英语集。没有新目的地任务时，不自动创建下一部、不运行旧片驱动。

## 2. 知识与视觉资料

每个拟讲知识点登记一句可用表述、出处、核查日期、事实/传说/角色原创的类别。历史人物可由现有角色提及，不因此新增演员；传说用“人们讲过一个故事”等明确标识。引用名言时保留原文依据，无法核对时改为明确的白话转述。

每份照片/视频分别记录以下字段，不把知识页面引用当成图片许可：

```json
{
  "id": "landmark-angle-1",
  "place": "明确地点",
  "landmark": "具体地标",
  "page_url": "原始来源页",
  "original_url": "原图或原视频地址",
  "author": "已有记录或unknown",
  "license": "原页登记或unknown",
  "license_url": "已有记录或空",
  "captured_or_published_at": "已有记录或unknown",
  "viewpoint": "朝向/景别/可见轮廓",
  "season_weather": "已有记录或unknown",
  "local_path": "本集目录内路径",
  "sha256": "实际文件哈希",
  "intended_use": "地貌参考/动作参考/实际剪入",
  "rights_review_status": "pending或已核对的实际结论"
}
```

参考必须支持地标外形、朝向、承托山体和大致前后关系。季节、天气与光照单独标注；不要用不同照片任意拼出新地貌，或把地点切换当成真实步行导航。角色站台、石凳和互动可以艺术化，但不能写成已核验的实地设施位置。

## 3. 叙事与镜头

先排“角色想知道什么→观察到什么→理解发生什么变化”，再安排知识。每镜注明目的、地貌/道具、景别、前后动作、声音归属和环境运动。对白、画外音、静默风景、道具特写分别写清楚。

推荐的人工分镜字段：`shot_kind`、`onscreen_character_ids`、`offscreen_speaker_ids`、`dialogue_ids`、`environment_motion`、`rigid_landmarks`。其中部分是本次试片的额外字段，**不是当前工作台全部已经支持的正式请求参数**；现有后端仍有“说话者必须出镜、角色不能为空”的限制。正式产品化需先补契约，不能向旧接口随意传字段后宣称已生效。

常规英语教学集2～4张主图是共用默认；旅行片按实际地点/景别做最小预算。黄山的11张在用源图是本片结果，不是未来每集必须复制的数量。

同地点可切全景、角色中景、景物/道具近景。对白以同侧固定机位为主，旅行感可用小幅推拉/横移与有依据的切镜；新景别使用相应主图，不能让模型在一个连续镜头里重搭山峰。环境运动逐镜指定：

| 景物 | 可以变化 | 保持稳定 |
|---|---|---|
| 松树 | 细针叶、柔软末梢在风中摆动 | 主干、主枝长度、冠幅结构 |
| 云海 | 近层翻卷、汇合、开合，远层较慢 | 山峰轮廓、相对位置、观景岩面 |
| 溪瀑 | 水流、轻微水雾、现有树叶 | 石壁、桥、栏杆及角色尺度 |
| 温泉 | 波纹和适量水汽 | 池岸/园景、角色原衣服与干燥步道 |
| 石猴 | 由光照/云雾带来观察层次 | 石头本体，不活化成猴子、不长脸 |

静默段单列“没有对白、两角闭嘴”。无声的连续口型不能当成笑容或点头通过。必要时切纯风景，保持既有真实运动；黄山S11就是此类已确认修正。

## 4. 主图与材质

先准备一张有代表性的同框样图，同时审角色身份、自然动物骨架、柔软毛绒、服装/背包和地标。按当前用户授权推进扩图；明确已确认全套并“开拍”的任务不再重复请示。生成成功仍不是视觉验收。

默认图像链路为自部署Qwen-Image-2.1。黄山实际使用过25步/euler/simple/cfg1；这属于具体执行实例，下一集要保存当次真实图和参数，不把历史seed当通用风格保证。每张保留模型、参考文件/SHA、prompt、seed、prompt_id、输出尺寸、审核决定和否决原因。

Soda要有短腿、低而水平的犬类躯干和正常承重关系。默认自然犬坐、四足站立或四足跑，不能把35cm比例强行拉成长躯干。分别检查两只耳朵、黑白脸罩、短口鼻、棕眼、白胸腹/四爪、卷尾和小棕背包。轮廓收顺仍要保留胸颊毛束与纤维层次；不连续引用已退化候选，让材质越修越薄。

一张图中多个角色要分别核对物种。黄山曾用多张狗参考整图修正，导致Angela犬化；后来用局部修狗、保留其他像素及双角色参考解决。局部生成/掩膜合成须记录为实际方法，不能标成全帧原生重绘。

早期黄山底图包含内置imagegen历史来源，之后才按用户要求切到4090。完整来源链按记录保留，不能将早期素材重新标成Qwen从零生成。

## 5. 原声和原生拍摄

先保存逐句原声并实测时间，再确定单镜帧数和动作。已有完全一致的合格原音直接复用；修改视觉不重新调用TTS，也不通过加速/减速来凑时长。Soda/Angela的本片声线及原WAV路径见黄山制作索引；其他角色以当前人物库为准，声线未定不能借用其他人的声音。

视频提示词优先用现有自部署写手，再检查**实际输出文本**。黄山发现过通用预设的woman/room示例泄漏、“山峰和云一起漂动”等错误。不得因brief写了约束就假定最终prompt正确；单片适配不能修改共享写手预设或节点。

原生基线：H3 Ref2VA FP8、turbo4step LoRA强度1、4 steps、euler/beta、768×1376、CFR24。单次约2–10秒，长片通过审核后的短窗续接；不要把过去较长一致性片段的体验理解为“单次任意30秒或整集可控”。

- 载体384×688，只含本段原声及必要静音。
- 连续机位同一高清主图，只继承实际保留末尾22帧无损画面，不接旧音频或AV latent。
- 续段原生时轴 = 成片段内时轴 + 22/24秒。给写手的`start/end`统一为raw时轴，避免与另一套`raw_start/raw_end`并存后被选错。
- 采样长度对齐17k+5；裁头部上下文后只保留计划N帧，再导出这N帧真正末尾22帧。
- 补动作状态用同一机位、相同尺度的不同关键状态。图的位置对、角色对还不够；不匹配当前推近尺度的中间图会制造硬跳。
- 关键帧不是越多越好。需要时用可区分的眼神/口型/尾巴状态约束四足；不能反复钉同一首帧或直接复制输出帧冻结角色。

服务器通道、只读连接自检及当前启用端口见通用交接文档。提交前查空闲队列，使用新输出前缀并持久保存prompt_id；断线查原history，未知状态不重复投。历史黄山脚本内有固定项目、asset和时间，先读代码，另建新集执行器，不直接运行。

## 6. 审查与返工

先核对实际首图、载体、声音、prompt、模型图及guide；按来源问题修正后再生成新候选。每条都看完整动态与接点，抽帧/像素差只作辅助。

| 检查项 | 放行依据 |
|---|---|
| 身份/材质 | 同角色脸型、花色、眼色、服饰、背包；纤维与外轮廓对照认可图 |
| 动物姿态 | 四腿结构与自然承重，未半直立挥手、长臂、丢腿或增耳；自然小幅换重心单独判断 |
| 逐句声音 | 当前说话者对原配音；听者闭嘴；同一角色连续两句不被误分给另一人 |
| 静默镜头 | 没有连续无声口型；有闭嘴反应或有效风景/道具运动 |
| 地貌 | 标志轮廓与方位保持，主峰/主枝不随云/风被重造 |
| 切点 | 同机位保留姿态与尺度；换景别是有目的的剪接，不用淡融/静帧遮问题 |
| 技术 | 实际保留帧数、CFR24、声音/字幕时刻、无多余尾巴、无静帧补长 |

黄山有四分之一秒身体联系表、逐句说话者采样、最后回应全部93帧检查和成片接点检查。**这些是该次审核证据，不是自动检测器**；静默嘴型仍被用户指出过一次，最终以云海空镜修正。不要沿用旧`technical_select`覆盖用户后续反馈。

多次仍失败时，可以调整视角、景别或用动作承接切镜。讲松枝时用枝条近景、无对白时看云海，都比反复强迫复杂同框动作更容易形成可用剪辑。禁止逐帧涂嘴、贴毛、循环末帧或用未使用的生成尾巴接下一段。

## 7. 后期、交付与接手

字幕/OP/BGM沿用已验证的本地流程；对白原样、计时按本集实测，中文大字幕与安全区看已有配方。只改画面时，完整原混音可直接复制AAC；只加BGM时复制画面码流。静默风景仍有环境运动，风水音/音乐来源要如实登记；黄山环境声为本地合成，不是实地录音。

服务器合成在当前进程明确指定现有FFmpeg9/ffprobe路径，避免系统FFmpeg4逐接点丢帧；不能用复制帧补齐。OP/正文颜色元数据也可能影响抽帧过滤器，精确时刻需逐帧或按通用交接方法验证。图像取景时保留原SAR；黄山原片为1080×1932、SAR644:645，不能在concat的一个分支突然强制1:1。

局部问题优先局部后期。黄山V3只重取景152帧；为完整GOP只编码1276–1624帧，其余视频码流复制。最终3325帧，完整音频码流一致，另外2977帧解码像素一致。这个具体范围不能复制给下一片；必须从新文件实际keyframe与剪辑边界重新计算。

用户确认后复制已审片文件归档，避免再次重编码；保存验收原话、最终SHA、SRT、manifest、校验与来源索引，再更新本作品release入口。交付不自动等于平台上传或工作台采用。上传平台或第三方媒体服务需要已有明确授权；私密配置和模型凭据不写进文档。

## 黄山V4补充：环境分层与行动收尾

完整做法和真实参数见[已认可配方](../../recipes/huangshan-pine-village-v1/README.md)，不是任意影片一键脚本。角色/口型已好而环境跳变时，先评估固定机位的局部分层；保护角色，主干/山形固定、针叶末梢微动。掩膜、运动和源像素如实登记，不能把程序风动合成说成全帧原生生成，更不能套用到逐帧涂嘴贴毛。全帧guide也要检查背景尺度，不只看角色。

温馨结尾用“对望→转身→同行走远”的完整行动，配同侧慢拉远、暖灯与水汽。首图先检查干燥步道连续可达、池水和栏杆不挡路、四足狗与直立羊分别成立。按实际图写初始朝向；拍后单独审静默嘴型、转身和脚步。多余无声口型能剪就裁，保留自然动作，长度以干净素材为准。本片生成10秒，裁头1秒，用9秒收尾；不是固定长度模板。

无对白片尾延长只处理音乐/环境音，原对白与字幕时轴保持；需要PCM前缀逐样本一致时直接按样本边界复制，再与处理后的尾音拼接。重新编码AAC后不能声称全声音轨编码包一致。载体仍用384×688，与高清主图及768×1376输出分开管理；显存错误先查原history，证实失败后再按明确原因恢复，不重启共享服务。
