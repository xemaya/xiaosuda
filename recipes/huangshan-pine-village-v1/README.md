## 最有用的结论

**先判断哪里坏了，再决定重拍多少。** 角色表演、口型已经成立，只有松树跳变时，拆开角色与背景处理能保住已认可的成果。只有镜头的意图变了，例如从“看温泉”变成“并肩进村”，才另做主图和完整动作。

温馨收尾需要一件正在发生的小事：两小只对望、转身、沿路同行，镜头逐渐拉远，暖灯、水汽和树叶继续动。角色走远让旅程有延续感；不用追加总结对白，也不用停成静态合照。具体9秒是本片剪辑结果，不是之后每集的固定长度。

## 迎客松：保表演，局部修环境

问题在完整片17–18秒；所属S03为第267–463帧，即11.125–19.333秒。松冠出现突然收缩/恢复，原角色嘴型已可用。

1. 从**实际入片首帧**提取树冠参考，保留本机位尺度。源图裁切1080×720，缩为768×512，独立生成197帧连续风动；任务`j_252f5185a7f4408c`，seed `1018202611`，prompt_id `867ce6a4-9451-4a5a-a160-849eadf8d3dd`。
2. 树干、主枝、冠幅及山形固定，只让针叶、末梢轻微随风。仅靠prompt不能保证成功，仍检查完整动态。扩大取景的另一候选改了树形/机位，已经拒绝，不能因输出成功就采用。
3. 顶部使用通过审核的原生树冠运动；最低枝梢以实际首帧几何为底，做锚定的小幅连续风动，位移上界约x1.85/y3.05px。本片不是整帧原生重拍，必须如实记为**原生动态素材＋局部程序风动＋分层合成**。
4. 背景层最多到y990；姐姐头部用椭圆保护区`cx800, cy1060, rx280, ry270`排除，所有更低区域仍来自原镜头。空间羽化只柔化图层边缘，不是时间淡融。保护区和坐标仅适用于本片，换机位/角色位移需重新画、逐帧检查。
5. 全片按实际关键帧拆成`[0,267)`、`[267,464)`、`[464,3173)`及旧片尾。仅S03与新片尾编码，另外2976帧直接复制编码包。保留SAR644:645、CFR24和所有字幕时刻。

逐帧亮度差峰值在17–18.2秒由15.12降至1.12，是辅助证据；小差异也可能来自静帧，不能单凭此值放行。本次最终依据包含画面审核和用户认可。

适用条件：固定机位或可准确对齐，问题局限于环境层，能可靠避开角色/嘴型/肢体。复杂遮挡、角色穿过修补区、大幅视差或原表演本身错误时，不照抄此掩膜；重新设计镜头或原生返工。背景微风分层不是逐帧涂嘴、贴毛或冻结表演的新许可。

## 温馨片尾：先让画面具备可走的路

首版图的问题不是“气氛不够”，而是小狗偏直立、水池挡住前行路线。该图已拒绝，未用于拍摄。第二版把温泉移至右侧，干燥石路通往暖灯村舍；狗、羊各自的身份与姿态分别核对。

- 图像参考分工：原温泉图供材质/光照与园景；已认可四足Soda供犬类骨架和比例；已认可同框图供两角身份。使用自有4090 Qwen-Image-2.1，seed `1018202602`，任务`j_684c2ded27c34b3b`，prompt_id `29348dbf-550d-40d6-a8ce-94c9558dae89`。
- 写手必须看**最终选用的实际图**。图中两角尚在对望，提示词就要写小步转身再向村里走；不能照抄“开头已经背对镜头”，让模型硬跳姿态。实际词稿经自部署写手生成后检查，保留修订前后文本。
- H3一次连续生成约10秒：短暂对望→小步转身→并肩走远；镜头沿同侧缓慢拉远。Soda保持低而水平的犬类躯干、正常四足交替；Angela保持直立羊的两蹄步态，不能把四足规则套给两角。
- 水汽、波纹、树叶提供环境生命力，建筑与路径稳定。保留原服饰和背包，不加陌生路人。村舍是既有园景的艺术化延伸，不能把它标成某个已核验的黄山历史村落。
- 新视频开头1秒仍出现无声动嘴，尽管prompt写了闭嘴。因此只选原生第24–239帧，得到216帧/9秒；从闭嘴对望进入转身、行走，末尾仍在自然运动。静默嘴型必须独立审核，笑容不能自动豁免；不涂嘴，不补静帧。

最终视频源任务`j_2687ecbebce5416b`，seed `1018202612`，prompt_id `a33e5efd-4feb-45c9-84a6-6ccd9110823f`，原生网格243帧、保存候选240帧、最终使用216帧。这三个数字含义不同，不能混用。

## 声音与计算资源的经验

| 实际问题 | 本次处理 | 后续复用 |
|---|---|---|
| 把音频载体做成768×1376，引起CLIP编码显存不足 | 查原history确认失败，恢复成384×688载体，输出仍768×1376 | 高清主图、载体、输出分辨率分别记录；不以提高载体尺寸代替提高画质 |

## 下次怎么用

先按本轮任务定缺陷范围与验收点；直接沿用已获授权的角色、声线和风格。只修背景先试分层；重新设计结束动作则先审主图中的路、站位、转身空间和目标方向，再拍一个能完成的连续动作。最后审核四足、物种、耳朵、材质、静默嘴型、真实环境、接点与原声，用户确认后归档。

只读校验，无网络、GPU或TTS：

```bash
python3 recipes/plush-dialogue-v14/verify.py
python3 recipes/huangshan-pine-village-v1/verify.py
python3 docs/travel/verify_huangshan.py
```

本片更细的编码包/音频PCM复核见`jobs/1018-huangshan-pine-village-v4/verify.py`。它会写本次实例的技术报告；报告里的pending为生成时历史状态，以[user-confirmation.json](user-confirmation.json)覆盖后续验收解释。

`recipe.json`登记实际资产、参数、保留范围和来源。`frozen-files.json`按工程相对路径冻结关键图、动态层、原片、原声、脚本、词稿、回执包及认可成片。此为**依赖本工程素材的引用式配方**，不是独立素材ZIP；大部分其他镜头原WAV和无损尾帧仍在服务器。脚本含固定项目ID、像素坐标、路径及本片时长，不能直接用来给下一站开拍；先按新片数据适配，不自动重跑模型。
