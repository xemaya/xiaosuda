跨agent制作接手先读`docs/agent-handoff.md`。现有工作台提供版本与基本制片流程，特殊动作中间帧、视觉审核与部分后期仍需要agent按集操作；生成回执与后端结构校验不能替代材质、动物姿态和口型验收。

环游世界/真实地点旅行线另有[专门接手文档](../docs/travel/README.md)。黄山最终片在本地release，工作台源项目尚未采用该完整剪辑；画外音、纯风景镜头与复杂guide有单片适配，不能视作通用工作台功能已经上线。

入口：**https://soda.buplayground.cn/**。独立 FastAPI 服务、SQLite 数据库和持久任务队列，沿用 buplayground 登录；不改动 Short Video 的代码、作品或 GPU 服务。

## 当前系列口径

以 `docs/series-bible.md` 为准：少儿英语情景剧，单集含包装不超过5分钟，可分部分，不强制教学→练习。人物正式名为 Soda、Jacky（奇奇）、Angela（露露）、Dad、Mom、Mimi（小咪）；栗子为已有保留角色。历史《How are you?》为技术样片，不约束新剧集的内容或编号。场景与画风页可查看并下载统一口径。

Mimi 已有新版角色卡、33cm比例和固定棕金眼/棕项圈金铃铛设定；具体声线待试听，涉及她的对白会在任何配音及GPU提交前拦截。

镜头支持全景、中景和特写，每个机位分别确认主图。人物不说话时可有自己的背景活动；Jacky喜欢单簧管、足球和搭乐高，Angela喜欢看书和编织。分镜可选“下拉换景 · 影片转场”，后期以8帧向下揭幕连接真实运动画面，只重叠静音缓冲并校准字幕；缓冲不足时保留原音并拦截合成。

## 原声与片头时间线

剧情设定确认后可先准备逐句配音、试听并查看实际秒数；相同台词、声线、音高和语速直接复用已保存原声，拍摄不重复调用配音。声线未定的演员在任何计费请求前拦截。

片头支持最前面或指定镜头之后，以保留冷开场。原声、画面和后续字幕按CFR24时间线一起编排。

## 使用

1. **剧本**：粘贴原文，或一次导入 1–50 个 TXT/MD 文件；JSON 支持 `[{"title":"片名","script":"完整剧本"}]`。每份分别保存。默认允许写手从七位固定伙伴里按剧本选角，也可手动限制候选。
2. **剧情设定**：查看并修改剧情、演员、场景和逐句对白。确认后生成场景主图，或沿用符合角色/画幅/道具约束的原主图。主图候选需要预览并采用。
3. **分镜**：写手读取已确认设定及真实主图，安排机位、完整动作、原对白和接续方式。单次 2–10 秒；同一连续机位继承实际保留的画面末尾。确认后才拍摄。
4. **拍摄**：按已认可声线配音，实测时长后生成实际提示词与载体，调用原生 H3。逐镜看视频并采用版本，支持单镜新拍；再在本地合成，加入所选 OP，只有分镜安排练习时才加入 A 幕间，并生成字幕。各轮、各镜和最终候选分别保留，可下载。

栗子已有角色卡，可以参与设定和无对白拍摄，但声线尚未定稿；涉及它的对白会在提交配音前拦下，不冒用其他角色声线。

## 固定范围

人物来自 `characters.md` 与现有七张 `sheets/`。服务器校验人物 ID、相对比例、固定设计和声线；没有添加角色或更换画风的入口。人物库和风格 ID 在后端固定，镜头引用、每句对白覆盖及阶段来源版本也在后端复核。

图像/表演的实际一致性仍需逐版审看，生成成功不等于已采用。场景图不会自动进入拍摄；镜头候选不会自动替换已采用版本。原第一集、OP 和 A 母版均为只读参考。

## 执行与恢复

- 写手：现有自部署 writer；视频分镜和配音时间对齐复用工作台 `h3-video-writer` 预设，冻结预设与执行图。
- 图像：现有 Qwen-Image-2.1，固定人物卡和美术约束；每个机位一张干净竖版主图。
- 2026-10-17 用户指定手动制图也优先走同一4090自部署生图/改图流程，Codex主要审核，不能把内置imagegen的出图标成4090生成。小苏打先核对顺贴、圆润的毛绒轮廓与原身份，再采用到机位；尖刺翘毛、逆光炸毛不得因“高清细节”而放行。单张毛型对照记录见 `jobs/1017-soda-fur-qwen-v1/`，未定稿候选不批量覆盖现有角色图或镜头。
- 配音：MiniMax speech-02-hd，读取现有私有配置；浏览器不接触密钥。已收到原音频时恢复转换，不重新计费请求。
- 视频：冻结的 `recipes/plush-dialogue-v14/continuity.py`，4 steps、euler/beta、24fps。续接只接22帧画面，不接旧音频或 AV latent；使用实际保留帧，另存22帧无损尾帧供单镜续拍。
- 所有任务有独立 UUID、冻结输入、版本和提交回执。断线/重启查询原 prompt_id，不盲目重复提交。待核对任务可以点击“核对原任务”。不打断共享 GPU，也不自动发布。
- 编辑原剧本会让后续待重新确认，旧结果仍保留。跨项目素材不能采用；旧主图/旧分镜不能冒充当前版本。

## 本机开发

```bash
SODA_DATA=/tmp/soda-dev SODA_AUTH=off SODA_WORKER=off python3 -m uvicorn workbench.app:app --host 127.0.0.1 --port 3214
python3 -m pytest workbench/tests -q
node --check workbench/web/app.js
```

仅 loopback 允许开发免登录；生产强制现有 gate 校验和同源写入。生产仅监听 127.0.0.1:3214，数据 `/data/app/huanghaibin/soda`。部署包有逐文件哈希、独立 systemd 服务和 soda 站点配置，保留前版本便于回退，不重启其他应用或 ComfyUI。

真实验收记录在 `evidence/`；本地合约测试不冒充真实 GPU 出片或用户验收。
