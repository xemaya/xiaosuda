# S1E02 一起出去玩！

Let’s Go Out and Play!

Soda：Hi, Jacky! What a beautiful day!
嗨，奇奇！今天天气真好呀！

Jacky：Hi, Soda! Yes, it is! Do you want to go out and play?
嗨，小苏打！是呀！你想出去玩吗？

Soda：Sure! That sounds fun! Where do you want to go?
当然！听起来真好玩！你想去哪儿玩？

Jacky：Let’s go to the park!
我们去公园吧！

Soda：Great idea! Let’s go!
好主意！我们出发吧！

Jacky：Come on, Soda! Let’s have some fun!
快来呀，小苏打！我们去玩个痛快吧！

Soda：Wait for me! I can run super fast!
等等我！我跑得可快啦！

Jacky：Haha! Let’s see who gets there first!
哈哈！看看谁先到！

Soda：Ready, set, go!
预备，开始，跑！

制作约束：角色外形、配色、背包、Jacky蓝卫衣白C与第一集正式片一致。仅家门口与公园步道两个地点，三个机位主图；按情景推进，不另插教学讲解或新对白。前置2秒OP，大字幕与轻声BGM沿用已定稿配方。
